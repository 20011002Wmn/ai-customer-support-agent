# AI Customer Support Agent

## Overview
This project explores how AI can answer customer support questions using a knowledge base.

## Objectives
- Explore customer support data
- Build a Retrieval-Augmented Generation (RAG) system
- Evaluate answer quality and reliability

## Tech Stack
- Python
- Pandas
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)

## Dataset
Bitext Customer Support Training Dataset.

Source: https://huggingface.co/datasets/bitext/Bitext-customer-support-llm-chatbot-training-dataset
